# SWC-107: SWC-107 - Smart Contract Weakness Classification (SWC)

## 描述
Smart Contract Weakness Classification and Test Cases

## 详细信息
请访问: https://swcregistry.io/docs/SWC-107

## 常见场景
- 外部调用后更新状态：攻击者可以在回调中重入
- 跨函数重入：通过不同函数重入

## 修复建议
1. 使用 ReentrancyGuard 的 `nonReentrant` 修饰符
2. 遵循 CEI 模式（Checks-Effects-Interactions）
3. 先更新状态，再进行外部调用
