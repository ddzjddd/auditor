# SWC-101: SWC-101 - Smart Contract Weakness Classification (SWC)

## 描述
Smart Contract Weakness Classification and Test Cases

## 详细信息
请访问: https://swcregistry.io/docs/SWC-101

## 常见场景
- 整数溢出：`uint256 x = type(uint256).max; x + 1` 会溢出
- 整数下溢：`uint256 x = 0; x - 1` 会下溢

## 修复建议
1. 使用 Solidity 0.8.0+（内置溢出检查）
2. 或使用 OpenZeppelin 的 SafeMath 库
3. 在关键计算前检查边界条件
