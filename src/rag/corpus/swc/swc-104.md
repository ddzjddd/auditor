# SWC-104: SWC-104 - Smart Contract Weakness Classification (SWC)

## 描述
Smart Contract Weakness Classification and Test Cases

## 详细信息
请访问: https://swcregistry.io/docs/SWC-104

## 常见场景
- 调用 `transfer()` 但不检查返回值
- 某些代币（如 USDT）不返回 bool 值

## 修复建议
1. 使用 OpenZeppelin 的 SafeERC20
2. 始终检查外部调用的返回值
3. 使用 `require(success)` 验证调用结果
