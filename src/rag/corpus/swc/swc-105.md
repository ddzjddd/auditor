# SWC-105: SWC-105 - Smart Contract Weakness Classification (SWC)

## 描述
Smart Contract Weakness Classification and Test Cases

## 详细信息
请访问: https://swcregistry.io/docs/SWC-105

## 常见场景
- 缺少访问控制的提现函数
- 任何人都可以调用关键函数

## 修复建议
1. 使用 `onlyOwner` 或 `onlyRole` 修饰符
2. 实现多签钱包控制
3. 使用时间锁延迟关键操作
