# SWC-116: SWC-116 - Smart Contract Weakness Classification (SWC)

## 描述
Smart Contract Weakness Classification and Test Cases

## 详细信息
请访问: https://swcregistry.io/docs/SWC-116

## 常见场景
- 使用 `block.timestamp` 作为随机源
- 依赖 `block.number` 进行时间计算

## 修复建议
1. 避免使用 block.timestamp 作为随机源
2. 使用 Chainlink VRF 或其他可信随机源
3. 使用 commit-reveal 方案
